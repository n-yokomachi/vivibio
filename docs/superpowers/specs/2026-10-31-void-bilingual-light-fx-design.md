# void の日本語透かし・ライトテーマ・背景演出 設計書

作成日: 2026-10-31

## 概要

void テーマと入口画面（Eye Gate）に次の5つの変更を入れる。

1. void の名前の行と bio で、カーソルの周りだけ下に重ねた日本語訳が透けて見えるようにする
2. 入口画面と void にライトテーマを追加し、右上のボタンでダークと切り替えられるようにする
3. void と入口画面の文字を大きくする
4. glitch のロケットと particle の粒子を、void の背景にボタンで出せるようにする
5. テーマの切り替えパネルを右下の隅に移し、目立たなくする

## 要件

| 項目 | 決定 |
|---|---|
| 透かしの対象 | 名前の行と bio だけ。資格・リンク・アウトプット・ステータス行は英語のまま |
| 透かしの日本語 | 名前の行は `横町 直樹 (yoko) — Software Engineer / AI Engineer`（肩書きは英語のまま）。bio は `PROFILE.bioJa` |
| 透かしの形 | カーソルを中心にした円。半径 80px、縁を 30px ぼかす。行単位ではなく、英語と日本語の2枚のレイヤーを重ねて円の中だけ日本語を見せる |
| スマホの透かし | 指でなぞっている間だけ円を出し、指を離したら消す |
| ライトの対象 | 入口画面と void だけ。minimal・glitch・particle・concrete は変えない |
| 初期の配色 | 保存した値があればそれ、なければ OS の `prefers-color-scheme` |
| 配色の保存 | 切り替えたら `localStorage` の `vivibio-scheme` に `light` か `dark` を保存する |
| 配色の切り替えボタン | 右上の隅に固定。ダークのときは `[ light ]`、ライトのときは `[ dark ]` と切り替え先を表示する。入口画面が開いているときと void のときだけ出す |
| 背景演出のボタン | void の `[ back to the front page ]` の上に `[ rocket: off ]` と `[ particles: off ]` を並べる。押すたびにオンとオフが切り替わる |
| ロケット | glitch と同じ見た目と動き。オンの間は一定の間隔で画面を横切り、オンにした直後に1回目が飛ぶ |
| 粒子 | particle テーマの星と粒子。カーソルに反応する。void のリンクにカーソルを乗せると、粒子がそのリンク名の文字の形に集まり、離すと散らばる |
| ロケットと粒子の連動 | 両方オンのとき、ロケットは通り道の粒子を押しのける |
| 背景演出の状態 | 初めはどちらもオフ。保存しない。void から別のテーマに移ったときと入口画面に戻ったときは止める |
| テーマの切り替えパネル | 右下の隅に移す。普段は暗い灰色の `[ themes ]` だけを出し、押すかカーソルを乗せるとテーマの一覧が上に開く |

## 日本語の透かし

名前の行と bio を `.vd-bilingual` のブロックで包み、英語と日本語のレイヤーを CSS グリッドの同じセルに重ねる。

- 英語レイヤーには、円の中を透明にするマスク `radial-gradient(circle at var(--mx) var(--my), transparent 80px, black 110px)` をかける
- 日本語レイヤーには、円の中だけを見せる逆のマスクをかける。英語の文字の隙間から日本語が全部見えてしまうのを防ぐため、マスクは両方に必要になる
- `--mx` と `--my` はブロックの左上からの座標で、`pointermove` で更新する。カーソルがブロックから遠いときは円が外に出るので、英語だけが見える
- `bioJa` は「。」で2行に分け、英語の bio の2行と行の位置を揃える。日本語レイヤーの行の高さは英語と同じにする
- 日本語レイヤーは `aria-hidden="true"` と `lang="ja"` を付け、`pointer-events: none` にする。リンクやテキストの選択は英語レイヤーで受ける
- スマホでは `touchstart` と `touchmove` で円を動かし、`touchend` で円をブロックの外に戻す
- JS が無効なときは円の座標が初期値（ブロックの外）のままなので、英語だけが見える

## ライトテーマ

### 配色の決定と切り替え

- `<head>` の初期化スクリプトで、`localStorage` の `vivibio-scheme`、なければ `matchMedia('(prefers-color-scheme: light)')` から `light` か `dark` を決め、`<html>` の `data-scheme` に入れる。表示の前に決めるので、読み込み中の色のちらつきは起きない
- `theme-color` のメタは初期化スクリプトで配色に合わせ、切り替えたときも `SchemeToggle` が書き換える
- 保存した値がない人は、OS の設定が変わったら追従する。保存した値がある人は追従しない
- `localStorage` が使えない環境では保存を諦め、OS の設定に従う

### 配色

色は CSS 変数で持ち、`:root[data-scheme='light']` で上書きする。下の値はライトの初期値で、実装後に画面を見て調整する。

| 部分 | ダーク（現行） | ライト |
|---|---|---|
| 背景 | #000 | #fafafa |
| 入口のドット | rgb(76,76,76) | #c8c8c8 |
| 瞳 | rgb(238,96,195) | rgb(238,96,195) |
| void の本文 | #9a9a9a | #555 |
| 見出しと罫線 | #555 | #aaa |
| 強調 | #eee | #111 |
| アクセント | 現行の `--void-accent` | #c8409f |

- 入口の canvas はドットを描くたびに `data-scheme` から色を選ぶ。切り替えた瞬間に目の色も変わる
- ロケットの白い部分と、粒子の明るい青と白は、ライトでは背景に負けない濃い色に替える

## 背景演出

### 共通モジュール

glitch のロケットと particle の粒子の処理を `src/scripts/fx/` に切り出し、元のテーマと void の両方から使う。canvas とアニメーションのループは使う側が持ち、モジュールは状態の更新と描画だけを持つ。

- `rocket.ts`: `launch(w, h)`・`update()`・`draw(ctx)` と、押しのけに使う現在位置と半径（110px）を公開する。発射の間隔の管理も持つ
- `particle-field.ts`: `resize(w, h)`・`setPointer(x, y)`・`swarmTo(text)`・`scatter()`・`repel(x, y, r)`・`update()`・`draw(ctx)` を公開する
- 色はモジュールの引数で渡し、テーマごとと配色ごとに替えられるようにする
- glitch のピンクの粒子の網と、帯やずれの演出は glitch に残す

### void での動き

- `VoidFx` は void の文字の後ろに全画面の canvas を置く。`pointer-events: none` にする
- ループは「void が表示中」「入口画面が閉じている」「ロケットか粒子のどちらかがオン」のすべてを満たす間だけ動かす。満たさなくなったら止める
- 粒子がオンのとき、void のリンク行に `mouseenter` か `touchstart` で `swarmTo(リンク名)`、離れたら `scatter()` を呼ぶ
- 両方オンのとき、毎フレームでロケットの位置を `repel()` に渡す
- `prefers-reduced-motion: reduce` のときはボタンを出さない

## テーマの切り替えパネル

- 右下の隅に `[ themes ]` という暗い灰色の文字のボタンを置く
- カーソルを乗せるか押すと、テーマの一覧が上に開く。スマホでは押して開き、外を押すか Esc で閉じる
- 一覧の中身、選んだテーマを `vivibio-theme` に保存する処理、ハッシュの更新は現行のまま

## エッジケース

| ケース | 挙動 |
|---|---|
| 背景演出がオンのまま別のテーマに切り替える | ループを止め、ボタンはオフに戻す |
| 背景演出がオンのまま入口画面に戻る | ループを止め、ボタンはオフに戻す |
| ライトで glitch などに切り替える | 配色の切り替えボタンを隠す。`data-scheme` は残るが、ほかのテーマはそれを参照しない |
| 透かしの円がリンクの上に来る | 円は名前の行と bio のブロックの中だけで効く。リンクは影響を受けない |
| reduced-motion | 入口は現行どおり静止。背景演出のボタンは出さない。透かしと配色の切り替えは使える |

## 脅威モデリング

データの流れはブラウザの中で閉じる。外部への送信と API はなく、OWASP API Top 10 の対象になる経路はない。

| データ | 入る場所 | 扱い |
|---|---|---|
| `localStorage` の `vivibio-scheme` | 初期化スクリプト | `light` か `dark` のときだけ使い、それ以外の値は無視して OS の設定に従う |
| カーソルとタッチの座標 | 透かしのマスク、粒子 | 数値として CSS 変数と canvas にだけ渡す。保存も送信もしない |
| リンク名 | 粒子を文字に集める処理 | `profile.ts` の固定値を canvas に描くだけで、HTML として挿入しない |

1. `npm run build` が通ること
2. このMacの Chrome を chrome-devtools の MCP で操作して確認する
   - 透かしの円がカーソルについてくること、英語と日本語の行の位置が揃っていること
   - ライトとダークの切り替え、リロード後に保存した配色で開くこと、保存がないときに OS の設定に従うこと
   - 入口の canvas の色が切り替えに追従すること
   - ロケットと粒子のオンとオフ、リンク名の文字に集まる動き、ロケットが粒子を押しのけること
   - 別のテーマと入口画面に移ったときに背景演出のループが止まること
   - glitch と particle のロケットと粒子が、切り出しの前と同じに動くこと
   - テーマの切り替えパネルが右下で開閉し、ほかの4テーマで配色の切り替えボタンが隠れること
   - スマホの幅（375px）で崩れないこと
